# Template 3 — Signal HUD (reference build)

The answer key for the Template 3 playbook. An original dark, technical, motion-led portfolio: text-scramble headings, a live three.js wireframe centrepiece, Lenis smooth scrolling synced with GSAP ScrollTrigger, a pinned horizontal project gallery, a scroll-filled timeline and a terminal-style contact form.

Stack: React 19 + Vite + Tailwind CSS 4 + GSAP (ScrollTrigger) + Lenis + three.js + EmailJS.

```bash
npm install
npm run dev
npm run build
```

All content lives in `src/data/portfolioData.js`. Optional images: `src/assets/about/about-portrait.*`, `src/assets/projects/project-N.*` (the files here are placeholders).

Built during training at [TAP Academy](https://thetapacademy.com/).
